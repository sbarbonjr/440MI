# Textbook Strategy

For this course, a single book is probably not enough because the material spans:

- Python-based data analysis and machine learning
- software engineering
- MLOps and monitoring

## Recommended primary textbook

- `Software Engineering`, Ian Sommerville
  - Best anchor for Classes 7, 10, 11, and part of 12.
  - Strong fit with the original `delete/` presentations, which already follow a Sommerville-style structure for requirements and process models.

## Recommended ML systems textbook

- `Designing Machine Learning Systems`, Chip Huyen
  - Best modern anchor for Classes 1, 5, 6, 13, 14, and 15.
  - Strong on deployment thinking, iterative delivery, production constraints, and monitoring.

## Recommended practical companion

- `Practical MLOps`, Noah Gift and Alfredo Deza
  - Best for labs, repo exercises, Docker, CI/CD, packaging, and operational workflows.

## If you want just one official course book

Choose `Software Engineering` by Sommerville as the official textbook, then list the other two as recommended readings.

Reason:

- it aligns best with the legacy course material in `delete/`
- it provides the most stable theoretical structure for the software engineering half
- the ML/MLOps content can then be complemented with lecture notes and selected papers
